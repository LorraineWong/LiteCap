# Security policy

## Supported versions

Only the [latest release](https://github.com/LorraineWong/LiteCap/releases/latest) receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository
([direct link](https://github.com/LorraineWong/LiteCap/security/advisories/new)).

Include what you found, how to reproduce it, and which version and OS you used.
You should get a reply within a week. This is a one-person project, so please allow reasonable time for a fix
before disclosing publicly.

## Scope notes

- LiteCap is not code-signed or notarized; Windows SmartScreen and macOS Gatekeeper warnings are expected.
  Only download it from this repository's Releases page.
- The only network access is the optional, user-approved download of the Windows translation pack from this repository's releases.
